# data/genome_2021/

Genome 2021 보조 데이터셋을 둔다. 현재 메인 전처리/drop/user-sequence 파이프라인의 필수 입력은 아니며, raw EDA와 연구 참고용으로 사용한다.

원본 파일은 `data/genome_2021/raw/` 아래에 로컬로 배치한다. `data/**/raw/` 정책에 따라 원본 파일은 git으로 추적하지 않고 직접 수정하지 않는다.

raw EDA 코드는 현재 다음 경로 중 존재하는 위치를 인식한다.

- `data/genome_2021/raw/`
- `data/genome_2021/movie_dataset_public_final/`
