# Expired Plans

이 디렉토리는 LLM 친화적 프로젝트 문서 구조로 정리하기 전에 작성된 기존 계획서를 보관한다.

## 보관 사유

- 기존 계획서는 `plan/active/`, `plan/done/`, `plan/expired/` 상태 구분을 도입하기 전에 작성되었다.
- 일부 내용은 이전 문서 구조와 당시 산출물 상태를 기준으로 한다.
- 현재 작업을 시작할 때는 `PROJECT_GUIDE.md`, `todo.md`, `plan/active/`를 먼저 확인한다.
- 과거 맥락이 필요할 때만 이 디렉토리의 문서를 참고한다.
